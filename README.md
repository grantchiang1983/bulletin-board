# 📋 佈告欄 (Bulletin Board Dashboard)

現代化、高自訂性的動態資訊佈告欄 Web 應用程式。使用者可以在網頁上一鍵開啟「自由佈局」模式，隨心所欲地拖曳移動區塊位置、自由拉伸縮放每個功能區塊的大小，並具備自動儲存、範本切換與匯出匯入功能。

---

## 🌟 核心功能區塊

1. **🌤️ 各地氣溫與天氣概況 (`weather-temp`)**
   - 涵蓋台北、新北、桃園、台中、台南、高雄、基隆、新竹、宜蘭、花蓮、台東、澎湖等全台縣市。
   - 即時氣溫、體感溫度、相對濕度、紫外線指數 (UV)、空氣品質 (AQI)。
   - 未來 24 小時逐時氣溫曲線與未來一週預報。

2. **🛰️ 天氣雷達雲圖與降雨觀測 (`weather-radar`)**
   - 串接中央氣象署雷達回波圖、紅外線衛星雲圖與累積雨量圖。
   - 動態 60fps 雷達掃描與降水回波模擬。
   - 具備播放 / 暫停與透明度調整功能。

3. **🌀 颱風動態與路徑資訊 (`typhoon-tracker`)**
   - 即時颱風強度（輕度/中度/強烈）、中心位置座標、移動方向與時速。
   - 中心氣壓 (hPa)、最大陣風風速、7級風與10級風暴風半徑。
   - 視覺化預測路徑時間軸與海陸警戒區域通報。

4. **📈 股市即時行情與走勢 (`stock-market`)**
   - 台股大盤加權指數 (`^TWII`)、櫃買指數 (`^TWOII`)、美股三大指數。
   - 熱門權值股（台積電 2330、聯發科 2454、鴻海 2317、廣達 2382、NVDA、TSM ADR）。
   - 即時跳動模擬、分時走勢平盤對照折線圖、紅漲綠跌台灣市場標準。

5. **🏠 最新房屋買賣與實價登錄 (`real-estate`)**
   - 彙整台北市、新北市、桃園市、台中市、高雄市、新竹市最新刊登與成交資訊。
   - 總價（萬）、單價（萬/坪）、坪數、格局、捷運站步行距離與屋況標籤。
   - 支援依縣市快速篩選、關鍵字搜尋（路段/捷運）與總價/單價排序。

6. **📝 自訂便利貼與備忘錄 (`quick-notes`)**
   - 多彩卡片筆記、即時新增/編輯/刪除，資料自動保存於瀏覽器 LocalStorage。

7. **🕒 實時時鐘與萬年曆 (`clock-calendar`)**
   - 數位即時跳動時鐘、農曆日期、二十四節氣提示。

## 🛠️ 自由佈局操作說明

- **切換模式**：點擊右上角「✏️ 自由佈局」開啟編輯模式，按鈕轉為藍色「✓ 完成佈局」。
- **拖曳位置 (Drag)**：在編輯模式下，按住任意卡片頂部的深色把手列即可自由拖曳至想要的位置。
- **縮放大小 (Resize)**：在編輯模式下，拖拉卡片右下角的藍色調整柄，即可隨意改變卡片的寬度與高度（支援 12 欄響應式網格）。
- **新增區塊**：點擊「+ 新增區塊」彈出小工具庫，可重複加入想要的多個功能卡片。
- **移除區塊**：在編輯模式下點擊卡片右上角的「✕」即可自畫布移除。
- **預設版型**：提供「預設綜合全覽」、「氣象防災焦點」、「財經房產焦點」快速切換。
- **匯出 / 匯入**：點擊「💾 匯出」可下載當前版面 JSON 檔，透過「📂 匯入」可隨時還原個人專屬配置。

## 🚀 快速啟動

雙擊專案目錄下的 `start_app.bat`，或直接使用任何現代瀏覽器開啟 `index.html` 即可立即使用！

```bash
# 或使用 PowerShell 開啟
Start-Process "index.html"
```
